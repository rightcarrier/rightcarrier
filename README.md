# RightCarrier

**Право должно иметь носителя.**

Мы привыкли «покупать» фильмы, музыку, игры — но на самом деле чаще всего мы покупаем не вещь, а разрешение ею пользоваться. Разрешение можно отозвать. Вещь — нельзя.

RightCarrier — идея о том, что у цифрового права собственности должен быть носитель: как у песни есть диск, у книги — том, у монеты — золото.

Носители не умерли. Они эволюционировали: перфокарта → лента → дискета → CD → DVD → флешка → …следующий носитель. Каждый раз, когда объявляли «смерть носителей», они меняли форму.

RightCarrier — о праве, которое можно держать в руках.

*Право. Носитель. Владение.*
